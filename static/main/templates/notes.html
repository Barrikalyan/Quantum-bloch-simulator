Notes — Quantum Concepts

Quick reference cards to explain gates, density matrices, and reduced density matrices.

Quantum Gates (Quick)

Gates modify qubits (single- and multi-qubit). Common gates include:

  • H (Hadamard): creates superposition: H|0> = (|0>+|1>)/√2
  • X (Pauli-X): bit-flip (like NOT)
  • Z (Pauli-Z): phase flip
  • CX / CX (Controlled-X): two-qubit entangling gate
  • RX/RY/RZ: rotations around Bloch axes by an angle
Density Matrix

A density matrix ρ encodes both pure and mixed quantum states. For a pure state |ψ>, ρ = |ψ><ψ|. It is a positive semidefinite, Hermitian matrix with trace 1.

Uses: represents ensembles, compute expectation values, and evaluate purity.

Reduced Density Matrix

When you have a composite system AB, the reduced density matrix for subsystem A is ρ_A = Tr_B(ρ_AB) — you trace out (sum over) subsystem B. This describes A's statistics when B is ignored.

Why care? reduced states show entanglement and mixedness at the subsystem level.

Examples

Try these in the simulator:

  • H 0 — puts qubit 0 into superposition.
  • H 0\nCX 0 1 — creates a Bell-like entangled pair between qubits 0 and 1.
  • After running, select a single qubit and inspect its reduced density matrix & purity.
